버디아코니아 Toss 기존 홈 → **일상살이** → 한 끼 / 여행 / 지역 발견 → 기록 상세/저장.

웹사이트(Site)는 기존대로 독립 운영하고, Instagram은 원본 콘텐츠 발행 채널로 둡니다.

### 실제 연계 경로

1. **즉시 가능한 외부 유입:** Instagram `@ilsang.sari` 계정의 '프로필 편집 → 링크 → 외부 링크 추가'에서 위 Toss 공유 URL을 등록합니다. 권장 제목: `버디아코니아 · 토스에서 보기`.
2. **실제 Toss 앱 내부 연계:** 기존 토스 앱을 빌드·배포하는 원본 소스에 일상살이 항목을 추가하고, 그 프로젝트의 공식 SDK/라우팅 방식에 맞게 첫 기록 카드를 이식합니다.
3. **콘텐츠 등록:** 운영자가 확인한 사진/릴스와 캡션만 사용합니다. Instagram Graph API 권한이 확보되기 전에는 자동 동기화나 무단 스크래핑을 하지 않습니다.
4. **검증:** 기존 토스 앱의 QR/테스트 진입으로 검색·카드·저장·다시 열기, Android/iOS 접근성, 내부 경로, 출시 심사 제약을 확인합니다.
5. **승인:** 대표의 별도 **컨펌 종료 및 배포 명령 전에는 기존 Toss/Site 운영배포를 하지 않습니다.**

## 빌드·배포 안전장치

이 미리보기 폴더를 별도 신규 앱으로 출시하지 않습니다.
`apps-in-toss.config.ts`의 `appName`은 실제 기존 토스 앱의 콘솔 값을 명시적으로 주입할 때만 인식됩니다.
임의의 `birdiaconia` 이름으로 배포하지 않습니다.

```bash
cd toss
npm install
npm run dev         # 별도 개발 미리보기
npm run build:web   # 브라우저 정적 시안만 빌드
# 공식 기존 미니앱의 appName 검증 뒤에만:
EXISTING_TOSS_APP_NAME="<실제 콘솔 appName>" npm run build
```

위 명령의 빌드는 실제 기존 미니앱과 병합/배포를 의미하지 않습니다.
